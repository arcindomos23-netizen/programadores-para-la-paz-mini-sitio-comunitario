Respuesta:
Desde las primeras clases, mi forma de trabajar ha evolucionado drásticamente gracias al uso de un 
repositorio en GitHub. Al principio, coordinar los cambios era un caos, pero aprender a integrar la 
rama personal con la rama main mediante un git merge limpio —o un flujo fast-forward cuando era posible— 
transformó por completo nuestra dinámica de equipo. Ahora, cada commit y push se realizan con total confianza, 
asegurando que el código de HTML, CSS y JavaScript esté siempre sincronizado tras hacer un git pull. El 
verdadero salto de calidad ocurrió al conectar el frontend con Node.js y Express, manejando respuestas en 
formato JSON a través de una API propia. Implementar funciones con async y await junto a fetch nos permitió 
crear un tablero de mensajes dinámico y fluido. Además, este proyecto único fortaleció mi compromiso con la 
participación ciudadana y una cultura de paz, impulsándome a redactar un README claro, aplicar un login 
pedagógico y asegurar un lenguaje responsable y no estigmatizante en cada línea de código.
